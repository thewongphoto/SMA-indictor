# Documentation index

Start with the guide for the task you are doing. Android source is **0.20.0**;
iPhone web is **0.20.0**.
GitHub Actions is the authority for native-build completion.
In 0.19.1, Settings has no Market Data card; its request-log/manual-cache
instructions in older diagnostic guides are retained for maintainer reference.
Web backups remain under Settings → Saved lines; owner setup is opened at `/setup`.
